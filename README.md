# MuscleMap (v1.0.0)

**MuscleMap**은 2D SVG 인체 해부학적 근육 지도를 기반으로 운동 종목과 세트별 기록을 관리하고, 설정한 루틴과 실제 운동 기록을 비교하여 운동 현황을 직관적으로 이해할 수 있는 PC·모바일 반응형 운동관리 웹 애플리케이션입니다.

[앱 실행](https://minho-nim.github.io/musclemap/) · [GitHub](https://github.com/minho-nim/musclemap)

## 실행과 배포

Node.js 24에서 `npm ci` 후 `npm run dev`로 실행합니다. `npm run lint`는 타입 검사, `npm run build`는 일반 빌드, `npm run build:pages`는 GitHub Pages 경로(`/musclemap/`)에 맞춘 빌드입니다. `main`에 올리면 GitHub Actions가 검사와 Pages 배포를 수행합니다.

홈의 주간 일정에서 날짜를 선택하면 해당 요일의 루틴과 종목별 세트·횟수·중량이 표시됩니다. 종목을 누르면 안내를 보고, 루틴을 편집하거나 운동을 시작할 수 있습니다. 선택한 날짜는 일정 조회용이며 운동 기록은 실제 시작 시각으로 저장됩니다. 추천은 기존 규칙 기반 계산이며 외부 AI API 키가 필요하지 않습니다.

운동 기록은 브라우저의 IndexedDB에 저장되며 기기 간 자동 동기화되지 않습니다. 설정에서 JSON 백업을 내려받고 복원할 수 있습니다. 다른 실행 주소로 이동하면 브라우저 저장 공간이 분리되므로 먼저 백업하세요.

Planfit 공식 공개 화면과 제공된 참고 이미지를 바탕으로 일정·종목 목록의 배치를 개선했습니다. MuscleMap의 기존 색상과 운동 기능을 유지하며, Planfit의 모든 화면을 동일하게 재현한 것은 아닙니다.

## 🌟 핵심 기능

1. **블랙 + 라임 + 코랄 디자인 시스템**
   - **배경 & 표면**: 어두운 다크 모드 (`#101213`, `#1D211E`, `#292E29`)
   - **라임 (`#B4F34C`)**: 운동 시작, 세트 완료 버튼, 활성 탭, 주요 CTA, 목표 달성
   - **코랄 (`#FF806B`)**: 목표 주동근(Primary), 선택 근육 하이라이트
   - **옅은 코랄 (`#E9AB87`)**: 보조 협력근(Secondary)

2. **정밀 2D SVG 근육 지도 (`viewBox="0 0 400 800"`)**
   - **전면(Front) & 후면(Back)** 인체 벡터 근육 모델
   - **탐색 모드**: 근육 터치 시 해당 부위를 자극하는 종목 목록 및 추천 카드 실시간 노출
   - **운동 안내 모드**: 운동 세션 및 종목 상세 페이지에서 주동근(코랄)과 보조근(연코랄) 시각화
   - **자극 히트맵 모드**: 실제 완료된 세트 수, 운동 빈도(일수), 목표 달성도 기반 신체 착색

3. **부위별 대표 운동 & 나에게 추천 (규칙 기반 엔진)**
   - **대표 운동**: 주동근 일치도와 복합 다관절 우선순위 기반 정적 추천
   - **나에게 추천**: 내 루틴 등록 여부, 이번 주 미완료 부족 세트, 최근 7일 수행 이력을 종합한 결정론적 추천 및 근거 표시

4. **운동 종목 상세 가이드 (84개 기본 종목 + 사용자 정의)**
   - 단계별 수행 순서 (1, 2, 3...)
   - 올바른 호흡법 가이드
   - 흔히 하는 실수 및 안전 주의사항
   - 대체 가능한 운동 및 개인 최근 세트 기록 조회
   - **'오늘 운동에 추가'** 및 **'내 루틴에 추가'** 지원

5. **집중형 운동 기록 & 세트 자동 저장**
   - 최소한의 조작으로 빠른 중량·반복 수 입력 (±2.5kg, ±1회 퀵 버튼)
   - 세트 유형 지원: 본세트(Normal), 워밍업(Warmup), 드롭세트(Drop), 실패세트(Failure)
   - 56px 대형 세트 완료 버튼 터치 즉시 IndexedDB 자동 저장
   - 이전 세트 값 자동 복사 및 세트 취소/삭제 지원

6. **지능형 휴식 타이머**
   - 자동 모드, 수동 모드, 적응형 모드 (RPE 및 세트 유형에 따른 추천 휴식 계산)
   - Web Audio API 기반 신디사이저 차임벨 & 햅틱 진동 알림
   - 타임스탬프 델타 기반 화면 전환 및 새로고침 복원

7. **루틴 관리 & 주간 미완료 운동 감지 엔진**
   - 무분할, 2분할, 3분할, 4분할, 5분할, 사용자 정의 루틴 지원
   - 요일 고정형 / 순환형 루틴 관리
   - 주간 계획 대비 실제 수행 세트 비교 (타 종목 초과 달성이 미완료 종목을 부당하게 상쇄하지 않는 엄격 계산)

8. **운동 기록 분석 & 로컬 IndexedDB 백업**
   - Recharts 기반 일자별 볼륨 추이 및 부위별 완료 세트 차트
   - 종목별 개인 최고 기록 (PR) 및 추정 1RM (Epley 공식)
   - 완전한 JSON 데이터 백업(Export) 및 유효성 검사 기반 복원(Import)

## 🛠️ 기술 스택

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4 (Custom Design Tokens)
- **State Management**: Zustand
- **Local Database**: IndexedDB (Dexie.js)
- **Charts**: Recharts
- **Icons**: Lucide React
- **Sound**: Web Audio API Synthesizer
